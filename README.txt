CHURCH ATTENDANCE APP

Files
- index.html: app
- manifest.json and service-worker.js: install/offline support

Publish
Upload all three files to a static web host such as GitHub Pages. Open the published address in Safari on the iPhone, tap Share, then Add to Home Screen.

Storage
Counts are stored in the browser on that device. Use Export backup after every service. Clearing Safari website data or deleting the web app can erase local counts. This version does not sync between devices.
